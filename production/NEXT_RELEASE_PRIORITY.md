## Definition of “finished”
A book is not counted as finished until all of the following are true:
- 60 original illustrations generated
- all 60 illustrations pass species/anatomy/layout QA
- 128-page paperback interior built
- 128-page hardcover interior built
- paperback cover built to final manuscript geometry
- hardcover cover built from exact KDP hardcover template
- KDP Previewer issues resolved
- paperback proof approved
- hardcover proof approved
- Kindle title record created first
- paperback submitted second
- hardcover submitted third

## Parallelism rule
Multiple books may have artwork and metadata work active at the same time, but completion resources should favor the closest book to KDP-ready status so the catalog gains actual live titles instead of only planned assets.

## Immediate bottleneck
Approved original artwork is the gating item. The build configs, front matter, assembly rules, and QA tooling already exist. As soon as a book reaches 60 approved images, it should move directly into interior assembly and cover production without waiting for the rest of the catalog.
