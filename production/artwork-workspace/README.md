# Approved artwork workspace

Each book uses two 30-image batches. Only artwork that has passed visual/anatomy QA belongs here. Name approved files with the two-digit animal number first, for example `01_lion.png`.

Run the artwork validator before building an interior. Final source art should target 300 DPI, pure black line art on white, no text or watermark, and keep important linework inside the 0.50-inch safety target.
