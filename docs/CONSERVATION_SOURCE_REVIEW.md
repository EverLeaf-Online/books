# MIST° Animal Series — Conservation & Taxonomy Source Review

Review date: **2026-09-15**

Purpose: record the external-source checks used to close the remaining catalog naming/conservation gates before original artwork approval.

## Review rule

For Book 20, the working definition follows IUCN Red List terminology: **Critically Endangered (CR), Endangered (EN), and Vulnerable (VU) are threatened categories**. Near Threatened (NT) is not counted as threatened, so NT entries that weakened the `Endangered Animals` concept were replaced rather than left ambiguous.

Primary IUCN guidance:
- https://nrl.iucnredlist.org/resources/summary-statistics
- https://nrl.iucnredlist.org/

## Book 28 — Sharks & Rays

The last broad production labels were normalized to species-level subjects so the art pipeline no longer has to invent a species at generation/review time.

Final cleanup included:

- `Devil Ray` -> **Spinetail Devil Ray** (`Mobula mobular`)
