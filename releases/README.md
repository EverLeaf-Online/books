# Release Artifacts

This folder is reserved for final, immutable production outputs after a book has passed QA.

Do not place assembly proofs, placeholders, draft art, or unreviewed covers here.

Recommended layout per released book:
- `releases/book_XX/paperback/interior.pdf`
- `releases/book_XX/paperback/cover.pdf`
- `releases/book_XX/hardcover/interior.pdf`
- `releases/book_XX/hardcover/cover.pdf`
- `releases/book_XX/kdp/listing.txt`
- `releases/book_XX/QA.md`

For Book 1, existing submitted print files should be copied here only after the exact submitted binaries are available to the repo workflow. Current KDP state remains paperback in review and hardcover in review.
