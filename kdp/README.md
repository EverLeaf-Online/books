# KDP Metadata

Source-of-truth listing/upload metadata for MIST° books.

Use one text file per book. Keep author as **Paul Thach** and imprint/brand as **MIST°**.

## Publishing order
1. Kindle title record
2. Paperback
3. Hardcover

Coloring-book Kindle editions may be blocked as unsuitable for Kindle, but the Kindle title record still comes first in this workflow.

## Print standards
- Paperback: 8.5 x 11 in, B&W white paper, no bleed, matte
- Hardcover: 8.25 x 11 in, B&W white paper, no bleed, matte
- 128 pages
- 60 coloring pages
- $9.99 paperback target
- $17.99 hardcover target
- Use exact current KDP hardcover calculator/template for hardcover cover dimensions
